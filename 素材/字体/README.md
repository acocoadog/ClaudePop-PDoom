# 字体

| 文件 | 授权 | 用在哪 |
|---|---|---|
| `DotGothic16-Regular.ttf` | SIL Open Font License 1.1（[OFL.txt](OFL.txt)），[fontworks-fonts/DotGothic16](https://github.com/fontworks-fonts/DotGothic16) | 全片的 HUD、对白框、冲击大字 |
| `zpix.ttf` | **不随仓库分发**，要自己下载 | 第四部分尾奏花絮（`codeshots_h.py`）里的日文小字 |

## Zpix（最像素）

从 [SolidZORO/zpix-pixel-font](https://github.com/SolidZORO/zpix-pixel-font/releases) 下载 `zpix.ttf`，放到这个文件夹。个人和教育用途免费，商业用途要向作者购买授权，并且禁止二次传播，所以这里不放。

另外，中文房间的纸条用了 macOS 自带的 `/System/Library/Fonts/Hiragino Sans GB.ttc`（`codeshots_b.py` 的 `SLIP_FONT`），别的系统改成任意一款简体中文字体。
