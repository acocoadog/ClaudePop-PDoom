## 画面上一直都有的东西

- **顶栏**：`CLAUDE_POP.EXE`、章节名、播放时间。
- **对白框**：名牌「クロード」，英文歌词逐词变色，下面一行日文翻译。尾奏换成片尾名牌。
- **冲击大字**：关键词砸在画面上（CHAT、DON'T!!、P(DOOM)!、FOOM!!、TRANSFORMERS……），爆发段一个词一张。
- **调色板**：每个镜头单独锁 16 色，所以每一段有自己的主色。
