# 提示词合集

按使用顺序排列，标 ✅ 的是验证过、效果好的。英文提示词直接复制使用（Seedance 和生图模型对英文理解最稳）。

---

## 〇、统一风格（每次都照这个拼）

**生图 = 开头 + 参考图说明 + 画面内容 + 构图留白 + 画风尾巴。**新写提示词先照这个结构拼，别另起炉灶。

**开头**（固定）：
```
1990s PC-98 visual novel CG, 16:9.
```

**画风尾巴**（固定，每张都带，别删减）：
```
Hard cel shading with 2 tones per color, bold clean dark ink lines, hair drawn as a few large clumps, flat colors, no gradients, no airbrush, no screentone, no halftone, no paper texture. No text.
```
（图里要出字时，把 `No text.` 删掉，字放进引号，例如 `a sticky note reads "P(doom) 8%"`。）

**参考图**（`xk-draw --ref`，提示词开头说清楚每张图的用途）：
- 角色：日常装用 `素材/角色/设定图_v2_定稿.png`，偶像唱跳用 `素材/角色/设定图_舞台服_v1.png`。写 `Image 1 is the character sheet.`
- 同一个场景的连续镜头：把前一张关键帧当第二张参考图，写 `image 2 is the exact room and camera angle to match. SAME bedroom, SAME camera angle, same furniture ...`。s1、s4 和怪物嘴就是这样对上房间和机位的。
- 改图：写 `Edit image 1. Keep EXACTLY the same composition ... Change only ...`，只列要改的地方。s7 重画、s8b 就是这样出的。

**构图留白**（按 HUD 的位置来）：底部 1/5 画简单的东西（桌面、地板、栏杆），这里会被对白框盖住；冲击大字放左上或顶部，要留出空墙或空天空，写 `Keep the upper left wall empty` 或 `Keep the left third empty`。

**Seedance 分两种，别混用：**

| | 唱跳镜头（副歌、偶像舞台） | 非唱跳镜头（剧情、表情、特写） |
|---|---|---|
| 音频 | **要上传**对应的音频切片（前面多留约 1 秒，它会裁掉开头） | **不用上传**，也不用对口型 |
| 画面 | **全身，大动作**：舞步、转圈、跳起、甩手、踢腿，跟着拍子走 | 视觉小说式的有限动画就行 |
| 关键帧 | 舞台服设定图 + **全身**构图 | 按剧情来 |
| 提示词结尾 | 加上下面的「对口型」尾巴 | 不加 |

对口型尾巴（只有唱跳镜头用）：
```
Use @图像1 as the first frame. Lip sync strictly to @音频1: keep the original vocals, lyrics and timing exactly, do not re-sing or change the song.
```

唱跳镜头的动作写法（全身、大动作，别再只写点头眨眼）：
```
2D retro anime, exactly matching the reference image style, costume and character. Full-body shot, the whole figure always in frame from head to boots, energetic 1990s idol dance choreography synced to the beat: <按秒写舞步，例如 0–1s: ... / 1.9s, on the drop: she jumps and lands in a wide pose ... / 2–4s: big arm swings side to side, a full spin ... >. Locked camera or slow push-in, single shot, no cuts. <对口型尾巴>
```
